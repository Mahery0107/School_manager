# Frontend — Interface React

Interface de l'application Gestion École (React 19 + Vite + React Router).

Installation, fonctionnalités et règles de gestion : voir le [README principal](../README.md).

```bash
npm install
npm run dev     # http://localhost:5173 (les appels /api sont redirigés vers http://127.0.0.1:8000)
npm run build   # version de production dans dist/
```
